# Bahmni EMR System Customization 🏥

This repository contains custom configurations, modules, and workflow adjustments for the **Bahmni Electronic Medical Records (EMR)** open-source hospital information system.

## 🚀 Overview
Bahmni integrates OpenMRS, Odoo, and other tools to provide a complete hospital management and EMR solution. This repository focuses on tailoring the system to meet specific clinical and operational requirements.

## 🛠️ Key Features & Customizations
* **Clinical Workflows:** Adapting patient registration, consultation, and observation forms.
* **Localization:** Tailoring clinical data modules for local hospital environments.
* **Integration:** Aligning lab, pharmacy, and reporting workflows.

## 📂 Project Structure
* `/configs` — System configuration files and form definitions.
* `/modules` — Custom modules and extensions.
